# Этап 2 · Навигация и Обзор

Milestone: «Этап 2 · Навигация и Обзор». Issues: #10–#17. Порядок: #10 (каркас) → #11 → остальные.

## Цель

Приложение открывается сразу на машине и за две секунды отвечает «что с машиной». Частые действия — записать трату, обновить пробег — доступны в один-два тапа с любого экрана машины.

## Как должно выглядеть

**Шапка внутри машины:** слева «Toyota Camry ▾» и под ним госномер моноширинным (переключатель машин, #13), справа кружок с инициалом → профиль (#14).

**Нижняя панель** (#10), на всех экранах машины: Обзор · Журнал · [＋] · Напоминания (красный счётчик просроченных+скорых) · Расходы. «＋» — квадрат indigo со скруглением, приподнят, открывает форму записи в шторке (#15). Учитывать `safe-area-inset-bottom`.

**Обзор** (#11), сверху вниз:
1. Карточка пробега: «Пробег / 87 450 км / обновлён 3 дня назад» + кнопка «Обновить» (#12).
2. «Требует внимания» (до 3 штук, ссылка «Все»): карточка с цветной полосой слева (red — просрочено, amber — скоро), название, остаток, кнопка действия (появится в этапе 3).
3. «Расходы в сентябре: 12 200 ₽» (мини-график — этап 4).
4. «Последние записи» — 3 строки в формате журнала + ссылка «Журнал».
Пустые секции не показываются.

**Шторка** (#15): выезжает снизу, затемнение, закрытие тапом по фону / свайпом / Esc. Форма записи: 5 кнопок типа с иконками → «Что сделали» с подсказками из прошлых описаний → сумма крупно → пробег и дата в одну строку → «Категория, место, заметка» свёрнуто → кнопка «Сохранить» прибита к низу.

## Решения

- Маршруты вместо `?tab`: `/cars/[id]` — Обзор, `/cars/[id]/entries` — Журнал, `/cars/[id]/reminders` — Напоминания, `/cars/[id]/expenses` — Расходы (заглушка до этапа 4). Старые `?tab=reminders` (в т.ч. ссылка в push, `server/utils/push.ts`) — редиректить.
- При одной машине `/` и вход ведут сразу на её Обзор; при нескольких — на последнюю открытую.
- Настройки push и выход переезжают в `/profile`, из `/cars` карточка уходит.
