# Этап 1 · Быстрые победы

Milestone: «Этап 1 · Быстрые победы». Issues: #26 (тесты — первой), #1–#9.

## Цель

Заметно улучшить ежедневное использование без смены структуры экранов. Только фронтенд, API не меняется.

## Как должно выглядеть

**Строка журнала** (#3): `[иконка типа в цветном квадрате] Заголовок ........ 6 800 ₽`, под заголовком мелко `12 сент · 87 200 км · Сервис на Ленина`. Заголовок = описание → категория → тип. Вся строка — ссылка на запись, кнопок на строке нет.

**Журнал** (#4, #5): поиск → строка чипсов типов (Все · ТО · Ремонт · Замена · Покупки · Прочее) → группы по месяцам: заголовок `СЕНТЯБРЬ 2026 ........ 12 200 ₽`, под ним карточка со строками.

**Цвета типов** (#2): ТО — indigo, ремонт — red, замена — orange, покупка — emerald, прочее — slate. Иконки (Lucide): ТО — calendar-check, ремонт — wrench, замена — refresh-cw, покупка — shopping-cart, прочее — more-horizontal.

**Форма записи** (#7): пробег по умолчанию — текущий пробег машины, дата — сегодня (локальная), сумма крупнее остальных полей, цифровые клавиатуры.

## Решения

- Даты: «12 сент», год добавляется только если он не текущий.
- Суммы: «6 800 ₽» — неразрывный пробел, символ валюты вместо кода.
- Группировка по месяцам и суммы групп считаются на клиенте; при сортировке по пробегу групп нет.

## Контракты

_Заполняется по ходу: утилиты форматирования (#1), компонент иконки типа (#2), где лежат цвета типов._
