# Дизайн «Гаража»

`garage.pen` — макет редизайна приложения (Pencil, pen.dev). Это источник истины для UI: при реализации экранов сверяйтесь с ним, а не с текущей вёрсткой.

Файл зашифрован — открывать только в Pencil (или через Pencil MCP), читать как текст нельзя.

## Что внутри

Мобильная ширина **390 px**, светлая и тёмная темы (переменные с осью `mode: light | dark`).

| Фрейм | Содержимое |
|---|---|
| `01 · Цвет`, `02 · Типографика`, `03 · Пространство и движение` | Токены: палитра (бренд, нейтральные, семантика, статусы напоминаний, типы записей), шрифтовая шкала, отступы `sp-*`, радиусы `r-*`, тени, зоны нажатия, анимации |
| `04 · Иконки` | Единый линейный набор иконок и правила использования |
| `05`–`07 · Компоненты` | Кнопки, поля, чипы/сегменты/toggle, бейджи, строки списков, карточки, графики, скелетоны, шапки, TabBar, шторка, диалог, toast, алерты, пустые состояния |
| `А`–`И` · Экраны | Вход и первый запуск, Обзор машины, Журнал, Напоминания, шторки записи и напоминания, Расходы, Профиль и настройки машины, диалоги и ошибки — с состояниями (загрузка, пусто, ошибка) |
| `Т1`–`Т8` | Ключевые экраны в тёмной теме |
| `Сценарий · 1–5` | Цепочки экранов: первый запуск, запись о ТО, создать/закрыть напоминание, обновить пробег, пригласить участника |
| `08 · UX-аудит и изменения логики` | Что было неудобно и какие изменения логики/бэкенда/модели данных предлагаются, с приоритетами |
| `Logo / App Icon`, `Logo / 72`, `Logo · Варианты` | Иконка приложения |

Экраны собраны только из компонентов (`reusable`) и токенов — новый элемент сначала добавляется в систему, потом на экран.

## Поддержка в актуальном состоянии

Решения из макета, которые становятся контрактами в коде (токены Tailwind, компоненты, изменения API и модели данных), фиксируйте в `docs/plans/conventions.md` по правилам из его шапки. Если реализация осознанно расходится с макетом — обновите `garage.pen` или отметьте расхождение там же, в `conventions.md`.
