# Plan Generator

## Порядок действий

1. Прочитай файл плана (формат — см. `docs/plans/redesign.md`, раздел «Как читать план»).
2. Для каждого раздела `### Этап N: название` создай milestone с тем же названием:
   `gh api repos/:owner/:repo/milestones -f title="Этап N: название"`
   Название обязано начинаться с `Этап N` — по нему Ralph (`ralph/lib/pick-issue.mjs`) сортирует задачи.

3. Для каждой задачи этапа создай Issue:
   `gh issue create --title "..." --body-file <файл> --label "..." --milestone "Этап N: название"`

**Title**: жирный текст строки задачи (без `- [ ]`, `**` и меток).
**Body**: вложенные пункты задачи как есть (Макет, Файлы, Контракт, Готово) + строка `План: docs/plans/redesign.md, этап N`. Тело передавай через `--body-file`, а не `--body`: в тексте есть кавычки и обратные апострофы.
**Labels**: метки из `[...]` в строке задачи; только существующие (`gh label list`). Метку `tests` не добавляй сам — Ralph берёт такие issue вне очереди.

4. После создания проставь номера issues в план рядом с задачами (`- [ ] **…** [метки] #N`), чтобы план и бэклог были связаны.
